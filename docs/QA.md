| `npm test` | 70 успешных тестов, 5 файлов |

Проверено на Windows, Node.js 24, Phaser 4.2.1, Vite 7.3.6, Vitest 3.2.7, Playwright 1.63.0, Python 3.14.7 и установленном Microsoft Edge в headless-режиме.

12 Python-тестов выполняют реальный сгенерированный код: все visible/hidden cases десяти уровней, типочувствительное сравнение и порядок объединения веток. В окружении без Python эта дополнительная группа пропускается; остальные тесты не зависят от интерпретатора.

## Браузерные сценарии

1. С чистого поля перетащены Source/Output, порты соединены мышью, запущена анимация, получено 5/5, перезагрузка восстановила граф и прогресс.
2. Машина перемещена за корпус, координаты привязаны к сетке; undo/redo возвращают ожидаемые позиции.
3. Pause удерживает ticks, Step увеличивает их на одно событие, редактор заблокирован; Instant завершает запуск, Python/JavaScript Code View отображает граф.
4. В инспекторе изменена Constant; несовместимый тип отклонён без повреждения графа. Шаг emit визуально создаёт пакет, transfer меняет вход MATH. Связь выбрана, удалена и восстановлена. Проверены zoom, pan, fit и уменьшение окна.
5. Через UI карты/импорта/RUN/Next пройдены все 10 уровней; reload сохраняет 10/10 завершённых заданий. Reference factories используются только тестами.

Размеры: 1366×768, 1920×1080, 1100×700. Скриншоты первого экрана и шага с пакетом были просмотрены. После увеличения читаемости и удаления внешних шрифтов браузерные сценарии повторно прошли.

Production проверка запускает отдельный HTTP-сервер только для `dist/` под `/algofactory/`. Проверены canvas, добавление машины, reload/autosave и отсутствие ошибок/внешних сетевых зависимостей.

## Исправленные регрессии

- Смена типа Constant/Join больше не может оставить несовместимую связь и сломать следующее чтение autosave.
- Недопустимая operation отклоняется при импорте, редактировании и запуске.
- Запуск с бюджетом, в точности равным числу событий, корректно завершается.
- Runtime-ошибка переводит тестовую панель в результат ошибки, после чего можно вернуться к редактированию.
- Python отличает boolean от number, в том числе внутри массивов.
- IR сохраняет порядок эмиссии при объединении веток независимо от порядка создания проводов.
- Packet виден уже на emit, а не только на transfer; Step остаётся наглядным при выбранном Instant.
- Сетка пересчитывает границы с учётом zoom; пакеты очищаются при новом запуске, ошибке и переключении на Instant.

## Масштаб и ограничения

Регрессионный тест исполняет 252 машины и 500 соединений, подтверждая порядок, результаты и event budget. Это проверка ядра, не обещание определённого FPS для любого компьютера.

Vite предупреждает о размере отдельного Phaser chunk (~1.39 MB minified, ~372 KB gzip); сборка успешна. Этот framework bundle сознательно отделён от приложения.

JavaScript export ограничен скалярными фабриками, Python поддерживает текущий набор. Графовые циклы, управляющие циклы, произвольная временная последовательность Memory read/write и мобильный интерфейс остаются вне MVP. Реальная публикация в GitHub Pages не выполнялась: проверен локальный production artifact и добавлен workflow для ручного запуска.
